# Teach It Easy

A student-first React frontend concept for discovering teachers and browsing their subject-specific study notes and YouTube lessons.

## Run locally

Install dependencies with npm install, then start the Vite development server with npm run dev.

## What's included

- Responsive landing page with teacher discovery and subject filters
- Search by teacher, subject, or teaching focus
- Teacher profiles with sample notes and video lessons
- Note preview dialogs and YouTube topic search links
- Sample content is clearly labeled and ready to replace with real teacher profiles and resources

The current build is a frontend prototype. Accounts, bookings, uploads, and persistent resource storage are not connected yet.
